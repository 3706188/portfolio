# Pei-Ying Chou — Portfolio

Personal portfolio website showcasing frontend development projects, built with pure HTML, CSS, and JavaScript — no frameworks required.

🌐 **Live Site:** [portfolio.github.io](https://3706188.github.io/portfolio/)

---

## Features

- **Bilingual support** — Switch between English and Traditional Chinese via a floating language selector; preference is saved in `localStorage`
- **Responsive layout** — Sidebar + main content on desktop, stacks vertically on mobile
- **Project cards** — Hover overlay with image zoom effect
- **Sticky sidebar** — Profile stays fixed while scrolling through projects
- **Gradient background** — Subtle cream-toned gradient with `background-attachment: fixed`

---

## Projects

| Project           | Tech Stack                        | Description                                                                                      |
| ----------------- | --------------------------------- | ------------------------------------------------------------------------------------------------ |
| Accommodation Web | HTML, CSS, JavaScript             | Accommodation search site for Tianzhong Marathon participants, with RWD layout and JS pagination |
| Culture Web       | HTML, CSS, JavaScript, PHP, MySQL | Local culture showcase for Tianzhong, featuring image carousel and Google Maps API integration   |
| Whac-A-Mole Game  | Java, Swing                       | Classic Whac-A-Mole game with random generation, scoring system, and time control                |

---

## Tech Stack

- **HTML5** — Semantic elements (`<aside>`, `<main>`, `<article>`, `<nav>`, `<section>`)
- **CSS3** — Custom properties, Flexbox, CSS Grid, `position: sticky/fixed`, `backdrop-filter`, transitions
- **JavaScript** — DOM manipulation, `localStorage`, `data-*` attributes, event handling
